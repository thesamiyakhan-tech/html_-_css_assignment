Four Selector Types

1. ID Selector (#main-heading)

Ye heading ID selector se styled hai. ID unique hoti hai.

2. Class Selector (.box)

Ye dono box class selector se bane hain. Class ko hum baar-baar use kar sakte hain.

3. Element Selector (p)

Ye saare paragraphs element selector se styled hain.

Har p tag ka color same hoga.

4. Attribute Selector (a[target="_blank"])

Ye link red hai (target blank hai)

Ye link normal hai (target blank nahi hai)
