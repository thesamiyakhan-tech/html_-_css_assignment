Task 25: Design Choices Note

1. Font Pairing: Playfair Display (Serif for headings - professional) + Source Sans 3 (Sans for body - readable). This contrast makes it elegant.

2. Colour Palette: Navy #1a2e44 for trust, Orange #ff6b4a for CTA/highlight, Beige #fdf8f2 for soft background, Dark Gray for text (easy on eyes than pure black).

3. System: All colours/fonts managed via :root CSS variables. One style.css for all pages = consistency and easy update.

4. Layout: 800px centered container + card with shadow for modern clean look.
